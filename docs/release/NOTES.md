**GNARL beta** - a wavetable synthesizer for riddim and dubstep.

| File | For |
|---|---|
| `GNARL-Windows.zip` | Windows 10/11: VST3 + standalone |
| `GNARL-macOS.zip` | macOS (Apple silicon and Intel): VST3, AU + standalone |
| `gnarl-web.html` | the phone version, served by the website at /app |

Install notes are in each zip's README.txt. These builds are not code-signed
yet: Windows may show a SmartScreen warning, and macOS needs one Terminal
command (in the README).
