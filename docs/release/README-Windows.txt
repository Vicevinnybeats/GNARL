GNARL - wavetable synthesizer for riddim and dubstep
=====================================================

What is in this folder
  GNARL.vst3   the plugin, for FL Studio, Ableton Live and any VST3 host
  GNARL.exe    the same instrument without a DAW (standalone)

Install
  1. Copy GNARL.vst3 into  C:\Program Files\Common Files\VST3
     (or keep it anywhere and add that folder to your DAW's plugin paths).
  2. Rescan plugins:
       FL Studio: Options > Manage plugins > Find more plugins
       Ableton:   Preferences > Plug-ins > Rescan
  3. GNARL appears as an instrument by "Gnarl Audio".

If the plugin window is blank
  The panel needs Microsoft's WebView2 runtime. Windows 11 and updated
  Windows 10 have it; otherwise it is a free download from Microsoft
  ("WebView2 Runtime").

If Windows warns about the file
  This beta is not code-signed yet. SmartScreen may say "Windows protected
  your PC": choose More info > Run anyway for GNARL.exe.

PRESETS

The Presets folder holds GNARL's built-in sounds as .vital files. In GNARL
they are also in the preset list: click the patch name at the top. To open
one from the folder, use ADVANCED and the preset browser there.
