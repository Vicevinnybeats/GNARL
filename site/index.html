WHERE DO I PUT THE PLUGIN?

Anywhere you like on Windows — keep it in Downloads and add that folder to your DAW's plugin search paths. macOS needs the VST3 in ~/Library/Audio/Plug-Ins/VST3/.

THE PLUGIN WINDOW IS BLANK.

The machine is missing the WebView2 runtime. It ships with Windows 11 and recent 10, and is a free download from Microsoft otherwise — the interface is a web view, so without it there is nothing to draw with.

WILL IT RUN IN FL STUDIO?

Yes. Options → Manage plugins → add the folder → Find more plugins. It appears under Generators. Ableton is the same VST3: Preferences → Plug-Ins → rescan.

HOW MUCH CPU?

The voice section runs at 2× oversampling by default; 4× is available and measurably no cleaner, so it costs CPU for a difference you are unlikely to hear. The FX rack only oversamples when something nonlinear in it is switched on.
