    WHERE DO I PUT THE PLUGIN?

    Anywhere you like on Windows. Unzip into Downloads, double-click GNARL.exe to hear it with no DAW at all, and leave GNARL.vst3 in the same folder — then add that folder to FL Studio’s plugin search paths, or turn on Ableton’s VST3 custom folder, and rescan. macOS fixes the paths: ~/Library/Audio/Plug-Ins/VST3/ and …/Components/ for the AU.

    THE PLUGIN WINDOW IS BLANK.

    The machine is missing the WebView2 runtime. The interface is a web view; without it there is nothing to draw with. It ships with Windows 11 and recent 10, and is a free download from Microsoft otherwise.

    WILL IT RUN IN FL STUDIO?

    It is a VST3 and is built for exactly those two. Every build is loaded the way a DAW’s scanner loads it and checked for identical sound before it ships. A real FL Studio and Ableton session is the beta’s job — tell us what you find.

    HOW MUCH CPU?

    Oversampling is the dial that matters: the voices run at 1×, 2×, 4× or 8×, and 2× is the default. Unison is the other: seven voices per oscillator cost seven times one.
